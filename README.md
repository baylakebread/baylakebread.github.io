# Bay Lake Bread Company

Website for Bay Lake Bread Company, a mother-and-daughter sourdough microbakery
in St. Cloud, Florida.

Live: https://baylakebread.github.io/

English at `/`, Portuguese at `/pt/`, Spanish at `/es/`. Opening the root sends
you to the language your browser or phone is set to.

This repository holds the built site only. Photos are the bakery's own.
